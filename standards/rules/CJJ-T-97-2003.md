## Normative vocabulary

The standard uses the usual Chinese normative terms:

- 必须 / 严禁 — mandatory.
- 应 / 不应 / 不得 — mandatory unless a documented exception applies.
- 宜 / 不宜 / 可 — recommended or permitted.

The table below records the keyword and the project's interpretation. It does not upgrade a recommendation into a mandatory rule.

## Gaps and cautions

- **Title-block dimensions are not specified in this extraction.** CJJ/T 97-2003 uses the term 图标 and gives placement rules, but the exact field layout and dimensions belong to a title-block standard. `GB/T 10609.1-2008` is registered as metadata-only and has not been obtained in full. Do not invent dimensions.
- **Exact RGB/CMYK values are not extracted.** Section 3 contains legend graphics, but this extraction did not sample colours. Any sampled value must be labelled `sample-map approximation`.
- **Line widths and symbol sizes for every legend item are not extracted.** They require reading the legend graphics and tables in section 3.
- **The land-use classification reference is historical.** GBJ 137 is not the current 2023 land-use/sea-use classification. Use CJJ/T 97-2003 for drawing conventions, not as the current classification code list.
- The source is HTML, not a printed PDF; page numbers are not available. Clause numbers are the citation anchors.

## Follow-up

- Obtain a lawful copy of GB/T 10609.1-2008 before fixing title-block dimensions.
- Extract section 3 legend parameters only when a template needs them, and record each sampled value and method.
- Check whether CJJ/T 97-2003 has been replaced or supplemented by a newer national planning-drawing standard before claiming current compliance.
