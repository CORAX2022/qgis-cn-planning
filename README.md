# qgis-cn-planning

Open, reusable QGIS styles and layout templates for Chinese planning practice.

Status: **pre-alpha / project baseline**. No public release yet.

This repository is being established as the source of truth for styles, layout templates, validation tools, documentation, and reference projects. See `docs/` for the project scope and standards baseline once the baseline branch is merged.

## Scope

- Village and town planning
- Territorial spatial planning
- Historical and cultural heritage conservation
